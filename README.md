# Terminal Tanks: website

The website for [Terminal Tanks](https://github.com/ethanlabs101/TerminalTanks), a turn-based tank artillery game
that runs in your terminal and your browser.

**Visit it here: [ethanlabs101.github.io/terminaltanks-site](https://ethanlabs101.github.io/terminaltanks-site/)**

## What's on the site

- **Play**: the full game in your browser, with sound and saves. No install.
- **Catalog**: every tank, ammo type, paint, map, home screen and boss.
- **Workshop**: build your own tank from parts.
- **Jukebox**: all 277 songs from the soundtrack.
- **Cheat codes** and a **save editor**.
- **Downloads**: the desktop version, and the [Nintendo DS version](https://ethanlabs101.github.io/terminaltanks-site/ds.html).
