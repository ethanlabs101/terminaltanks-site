BUILD OR EDIT A SAVE FILE

Load your save, check what the game will make of it, change what you want, and download it again.

In the browser game, choose Save data, then Import backup. The downloaded game reads a plain save.json instead (see Install for where it goes). Either way, importing replaces the save on that device, so keep a copy of the original. To keep your real progress, settings, loadouts, custom tanks and story progress, load your own backup or save.json below and edit that. Everything runs in this page; nothing is uploaded.

Starting from a blank save. You can also drop a file here.
PROGRESS

Levels and missions are cleared in order, so 7 means 1 through 7. Clearing a level or mission also unlocks its rewards. If you load a save and leave these alone, its exact progress is kept.

WALLET
THE MARTYR'S TIME MACHINE

Defeating the Martyr grants his relics (six ancient tanks, five ancient ammo types, three sanctum maps, six home screens and the ASTRAL paint) and Martyr's Blessing, which nothing else can unlock. The game also opens the Time Machine once all ten ticket bosses are beaten.

LOADOUTS

The game resets a loadout to Ranger and Standard if the tank or ammo is not unlocked, and to Cyan and Yellow if an animated paint is not owned, so pick items you have also ticked or earned.
